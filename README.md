An entry for [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on make.fun.

A one-line museum placard for an ordinary office object, written as if
it were an ancient artifact dug from a lost civilisation.

## The entry

> Stapler, Office of Eternal Meetings, circa 1987. Forged in boredom, worshipped by interns, it binds what no one will ever read again. Do not touch. It remembers.

161 characters, one line, inside the gate of 1–180 characters.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the placard above, with no trailing newline.

## Files

- `main.py` — writes the placard to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
